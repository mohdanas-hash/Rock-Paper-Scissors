# Rock-Paper-Scissors
This is a classic Rock‑Paper‑Scissors game implemented in C++. The player competes against the computer, which makes random choices. The game keeps track of wins, losses, and draws, making it a fun way to practice basic programming concepts like conditionals, loops, and random number generation.
🛠️ Languages & Tech Stack Used
HTML5: Semantic markup structure (<header>, <main>, <aside>, <section>), SVG graphics for icons/charts, and <canvas> element for graphics rendering.

CSS3: Custom CSS variables, CSS Grid & Flexbox layouts, modern animations (@keyframes), dark cyberpunk theme styling, custom scrollbars, and responsiveness (@media queries).

JavaScript (Vanilla ES6+): Pure client-side logic with zero external dependencies.

Web Audio API: Built-in browser sound synthesizer using AudioContext and dynamic oscillators (sine, square, sawtooth, triangle) for retro sound effects without needing audio files.

HTML5 Canvas API: 2D particle explosion FX system rendered dynamically upon round outcomes.

Web Storage API (localStorage): Persists lifetime statistics (rounds, win rate, best streak, total matches) locally in the browser.
